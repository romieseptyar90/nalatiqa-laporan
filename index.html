Pilih Akun Toko Tujuan Impor:
Data transaksi pesanan & pencairan yang diimpor akan dicatat ke akun toko ini
Ingin mulai pembukuan dari nol? Anda dapat membersihkan seluruh transaksi lama sebelum mengunggah laporan baru.
Impor Laporan Keuangan Shopee
Format resmi: Shopee Seller Centre > Penghasilan Saya > Rincian Penghasilan (.csv bertitik-koma atau .xlsx)
Klik atau Tarik File Laporan Shopee ke Sini
Sistem otomatis mendeteksi pembatas titik-koma (;), format tanggal DD/MM/YYYY, mengaitkan baris Order dan Sku agar nama produk tampil lengkap, serta menghitung potongan admin, gratis ongkir XTRA, dan komisi AMS.
Impor Laporan Keuangan TikTok Shop
Format resmi: TikTok Shop Seller Center > Keuangan > Settlement / Income Statement (.xlsx / .csv)
Klik atau Tarik File Laporan TikTok Shop ke Sini
Mendukung file Excel (.xlsx) atau .csv langsung dari TikTok Seller Center. Otomatis membaca sheet Detail pesanan, biaya komisi, voucher, penyesuaian logistik, dan nama produk. Anda juga dapat memilih 2 file sekaligus (Income + Semua Pesanan)!
Impor Laporan Keuangan Lazada
Format resmi: Lazada Seller Center > Keuangan > Account Statement / Transaction Details (.xlsx / .csv)
Klik atau Tarik File Laporan Lazada ke Sini
Mendukung format Account Statement & Transaction Details Lazada resmi (.xlsx atau .csv bertitik-koma/koma). Otomatis membaca omset penjualan, komisi LazMall, potongan LazKoin, biaya payment fee, kurir LEX, dan nama produk.

SP
Panduan Ekspor Shopee Indonesia
  1. Buka Shopee Seller Centre (seller.shopee.co.id).
  2. Pada menu kiri, pilih Keuangan > Penghasilan Saya.
  3. Pilih tab Sudah Dilepaskan (atau tentukan bulan transaksi).
  4. Klik tombol Ekspor di bagian atas tabel untuk mendownload file .csv.
  5. Tarik atau pilih file tersebut pada kotak uploader di atas.
TT
Panduan Ekspor TikTok Shop
  1. Buka TikTok Shop Seller Center.
  2. Masuk ke menu Finance > Settlements (Penyelesaian Dana).
  3. Pilih rentang tanggal penyelesaian bulanan yang ingin dihitung.
  4. Klik tombol Export / Ekspor Settlement Statement format .csv.
  5. Unggah file tersebut ke aplikasi ini, data akan langsung dihitung otomatis.
LZ
Panduan Ekspor Lazada Indonesia
  1. Buka Lazada Seller Center (sellercenter.lazada.co.id).
  2. Pilih menu Keuangan > Laporan Akun (Account Statement).
  3. Tentukan periode atau nomor statement yang ingin dicatat.
  4. Klik tombol Ekspor / Unduh Transaksi format .csv.
  5. Tarik atau pilih file tersebut pada kotak uploader di atas.

Tips Praktis Pembukuan Iklan Meta (Facebook & Instagram Ads)
  • Iklan Berbayar Luar Platform: Iklan Meta dibayarkan secara terpisah menggunakan Kartu Kredit, Debit Online, atau Virtual Account (tidak langsung dipotong dari saldo pencairan marketplace).
  • Integrasi Laporan Laba Rugi: Seluruh biaya iklan Meta yang Anda catat di sini otomatis dihitung ke dalam Beban Operasional & Pemasaran (OPEX) pada Laporan Laba Rugi (P&L).
  • Meta CPAS (Collaborative Ads): Jika Anda menjalankan iklan CPAS yang mengarahkan traffic langsung ke toko Shopee atau Lazada, catat biaya ads-nya di sini agar margin bersih toko tetap akurat.
